# ContractAgent

A Spec-Driven Behavioral Contract & Verification Engine for Tool-Using AI Agents.

## Overview
ContractAgent brings **Spec-as-Source** engineering discipline to autonomous AI agents. Behavioral invariants, tool schemas, and multi-turn state transitions are defined in formal declarative specifications and enforced deterministically at runtime via Google Common Expression Language (CEL).

## Quickstart

```bash
# Install dependencies
uv sync

# Run tests
pytest
```
