# API Contract: Conversation Event Streaming Protocol

**Feature**: `003-conversational-agent-template`  
**Date**: 2026-09-24  
**Status**: Ready for Implementation  

---

## 1. Event Streaming Model

The `stream()` method emits an asynchronous sequence of `ConversationEvent` objects. Each event contains a discriminator `type` and associated contextual fields.

```text
User Message -> stream(message)
    |-- ConversationEvent(type=TOKEN, content="I'll ")
    |-- ConversationEvent(type=TOKEN, content="check that ")
    |-- ConversationEvent(type=TOKEN, content="invoice now.")
    |-- ConversationEvent(type=TOOL_CALL_START, tool_name="fetch_invoice", tool_args={"invoice_id": "INV-101"})
    |-- [GuardInterceptor evaluates invariants: INV-001, INV-002]
    |-- ConversationEvent(type=TOOL_CALL_RESULT, tool_name="fetch_invoice", tool_result={...})
    |-- ConversationEvent(type=TOKEN, content="The invoice amount is $50.")
    |-- ConversationEvent(type=STATE_CHANGE, new_state=AgentState.AWAITING_INPUT)
    +-- ConversationEvent(type=TURN_COMPLETE)
```

---

## 2. Event Payload Specifications

### 2.1 `token`
Partial textual response generated by the agent.
- `type`: `"token"`
- `content`: Non-empty string chunk (`str`).

### 2.2 `thought`
Internal chain-of-thought or reasoning step (optional / debug visibility).
- `type`: `"thought"`
- `content`: Reasoning trace text (`str`).

### 2.3 `tool_call_start`
Signals that the agent has decided to invoke a contract tool.
- `type`: `"tool_call_start"`
- `tool_name`: Name of the tool being called (`str`).
- `tool_args`: Dictionary of validated arguments (`dict[str, Any]`).

### 2.4 `tool_call_result`
Emitted after successful execution of a guarded tool.
- `type`: `"tool_call_result"`
- `tool_name`: Name of the tool (`str`).
- `tool_result`: Return value from the tool implementation.

### 2.5 `escalation_required`
Emitted when a CEL invariant triggers an escalation requiring approval.
- `type`: `"escalation_required"`
- `content`: Human-readable explanation of why escalation is required (`str`).
- `approval_token`: Unique token for resuming the action (`str`).
- `tool_name`: Target tool name.
- `tool_args`: Intercepted tool arguments.

### 2.6 `state_change`
Emitted whenever `agent.state` transitions.
- `type`: `"state_change"`
- `new_state`: Destination `AgentState` value.

### 2.7 `turn_complete`
Terminal marker signaling the end of the streaming turn.
- `type`: `"turn_complete"`

### 2.8 `error`
Emitted if an unhandled error or hard invariant breach occurs.
- `type`: `"error"`
- `content`: Error message text.
